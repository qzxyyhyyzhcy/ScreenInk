# 屏幕批注

适用于小米 Pad 6 Pro 的屏幕手写工具。将焦点笔 Plus 中「笔键 2 → 长按」设为「启动应用 → 屏幕批注」。也可以直接从桌面打开。

- 每次打开时读取当前画面。笔尖悬停显示笔刷位置和线宽，触控笔落下才绘画。普通批注时单指拖动画面，双指捏合缩放。
- 工具栏提供钢笔、荧光笔、橡皮擦、颜色、撤销及重做。点「更多」打开线宽设置，范围为 0.5–24 dp，每次可精调 0.5 dp。
- 「截图」将原始分辨率的画面与批注合成为 PNG，存入相册的「屏幕批注」目录。保存后右上角出现预览，点开可查看原图。
- 点色块右侧第一个图标进入滚动批注。单指直接滚动原页面，触控笔可以在移动的页面上批注。需要放大时点放大镜，用双指缩放和单指拖动画布，再点滚动图标继续滑动页面。
- 滚动批注时，色块右侧第二个图标保存长图，「更多 → 截当前页」保存当前视口。笔迹记录在页面坐标中，导出时随对应内容保留。该功能需要 Android 14 或更新版本，页面需要允许截图。滑动时尽量保留相邻页面的重叠区域。
- 右上角的叠窗图标可以从列表选择应用，在支持小窗的系统及应用上用手指操作。小窗保持独立，窗口范围内的触控笔操作不会留下笔迹，导出图片只记录被批注的页面。
- 左上角的叉号放弃当前批注。右侧对勾保存后关闭。再长按笔键 2 会读取当时的页面。

## 构建

批注内的笔键快捷操作需要在 LSPosed 中启用「屏幕批注」，勾选「系统框架」作用域并重启平板。主键短按在钢笔和荧光笔之间切换，长按启用临时橡皮，笔尖抬离画布后恢复原画笔。副键短按循环换色，批注打开时长按无动作。批注关闭时，由焦点笔 Plus 的映射打开批注。

构建时只使用 `compile-only` 中的 Xposed API 声明，运行时由 LSPosed 提供实际实现。

在 Windows 安装 PowerShell 7、JDK、Android SDK Platform 36 或更新的平台，以及 Build Tools 36.0.0。设置 `ANDROID_HOME` 后运行 `./build.ps1`。输出文件为 `out/ScreenInk.apk`。

首次构建在本机生成专用签名，放在 `.local-signing`，密码由当前 Windows 用户保护。更新前提高 `AndroidManifest.xml` 中的 `versionCode`，继续使用原有包名和签名即可覆盖安装。
